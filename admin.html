Send Order to Supplier
Format and dispatch order details directly to your supplier via email.

Developer Note: API Automated Integration

To send this email fully programmatically behind the scenes (without opening a mail client), configure a serverless endpoint to call the **Resend API** like so: 

fetch('https://api.resend.com/emails', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_RESEND_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    from: 'orders@shuchi.bd',
    to: supplierEmail,
    subject: `New Order Dispatch: ${orderRef}`,
    html: emailHtmlBody
  })
});
